MCP Docs

How this Studio talks to Tableau

What is this?

This app is a chat UI over Tableau MCP plus local data-app tools. You pick a published datasource, then the agent calls MCP tools (query-datasource, list-workbooks, publish-workbook, etc.

Datasource-first

Always select a datasource in Workspace first. Chat injects [Active Datasource | datasourceLuid=…] so every tool stays on that LUID.

Data apps (JS artifacts)

Prefer local_generate_data_app: invents fresh src/app.js + CSS, scaffolds, wires sqlproxy, writes preview, packages .twbx. Publish only when you ask via MCP publish-workbook.

  • Preview: /preview/<name>?v=…
  • Theme: red | green | blue in the brief
  • Samples projectId for publish is pre-filled in shortcuts
